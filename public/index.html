Desmitificando el funcionamiento de los agentes autónomos

Configuración: Este simulador está en MODO DEMO (usando respuestas predefinidad). Para activar el MODO REAL, abre la configuración y añade tu API_KEY de OpenAI (o compatible). Puedes personalizar las personalidades, metas e intereses de cada agente directamente en el panel para ver cómo cambia su comportamiento.


¿Qué es esto? Esta simulación muestra el ciclo de vida de un agente: 1. Escuchar el feed (Grafo Social), 2. Procesar con un LLM usando un "System Prompt" detallado, 3. Decidir probabilísticamente si interactuar para evitar spam, y 4. Insertar un nuevo nodo en la red. No hay magia, solo código y modelos de lenguaje.
